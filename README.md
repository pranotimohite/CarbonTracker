Carbon Tracker with AI Insights

A full-stack web application that helps users monitor their carbon footprint and receive AI-powered recommendations for reducing emissions.

Key Features

Track emissions from transportation, electricity usage, and lifestyle habits

AI-powered suggestions using OpenAI ChatCompletion API

Emission data visualization

REST-based backend services
